# Roadmap – Season 1 MVP

- **M0 Setup**: agents, CLAUDE.md, git, docs skeleton, XcodeGen project builds an empty landscape iPad app
- **M1 Core loop**: player movement, twin-stick controls, shooting, one enemy (Bolt-bot), placeholder art
- **M2 Levels**: procedural generator (BSP rooms + corridors), camera, minimap, door puzzle (buttons/levers/machines)
- **M3 Systems**: inventory (25 + 4 quick slots), loot drops, ammo/reload, heal packs and food, checkpoint rescue, Pixel drone buddy
- **M4 Content**: all 5 enemy types, 3 blasters, levels 1–5 data, boss (MEGA-MECH Unit Zero)
- **M5 Presentation**: AI-generated art integrated, audio, DE/EN localization, menus, save game
- **M6 Polish**: balancing, 60 fps on iPad 9th gen+, kid-safety review, TestFlight build

## Later (not MVP)
Game controller support, more seasons, more weapons, achievements.
