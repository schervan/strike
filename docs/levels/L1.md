# L1 – City Rooftop Lab (tutorial)

id `l1` · theme `rooftop_lab` · music `music_rooftop` · par 360 s · ★3 rescues ≤ 1 · fallbackSeed 1001

**Mood:** sunny rooftops, glass greenhouse-labs, antennas, pigeons (decor only). OVERMIND's first
robots are "borrowing" the city's solar panels.

**Goal for the player:** learn move, aim/fire, reload, interact, heal, quick slot.

## Tutorial flow (soft prompts, never blocking)

1. Start: ghost hand on left side "Move" until the hero walks 2 s.
2. First room: ghost hand on right side "Aim + shoot" until first shot.
3. Magazine empty first time → RELOAD button pulses.
4. First button within 64 pt → INTERACT pulses.
5. HP < 70 first time → Q1 pulses.
