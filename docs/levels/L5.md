# L5 – OVERMIND Core + boss

id `l5` · theme `overmind_core` · music `music_core` (boss: `music_boss`) · par 780 s · ★3 rescues ≤ 2 · fallbackSeed 5005

**Mood:** purple-gold energy halls, floating cubes, a giant glowing core. OVERMIND's face is
everywhere, making funny angry faces.

**Structure:** generated part (2 zones) → exit door → fixed boss arena (§9 GDD) → ending.
